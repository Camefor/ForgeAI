## 5. 文档维护约定

- 需求编号使用 `FR-*`，非功能需求使用 `NFR-*`，领域规则使用 `DR-*`。
- 重要技术决策使用 `ADR-*`（见 [`adr/`](./adr/README.md)），记录背景、选择、影响和替代方案。
- 任务 ID 使用 `<XX>-NNNN`，XX 为项目缩写（`INIT-GUIDE` 第 ① 步确定）。
- 阈值或关键规则修改必须同步更新 SRS、相关模块设计和测试方案。
- 接口、表结构和配置变更必须同步更新 API、数据库及部署文档。
- Markdown 文本统一使用 UTF-8 with BOM 与 CRLF 行尾。
