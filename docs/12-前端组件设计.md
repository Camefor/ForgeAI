> **填写指南**：本文件回答「组件怎么拆、状态怎么管、怎么通信、怎么保证性能」。技术栈无关；具体框架（React / Vue / Blazor / 小程序原生）在 `03-SAD` §2 确定。

## 1. 组件分层

> **填写指南**：按职责分层。常见分层：原子组件（Button / Icon）/ 复合组件（Form / Table）/ 页面级组件 / 布局组件。每层说明可依赖与被依赖的层级。

| 层级 | 职责 | 可依赖 | 典型组件 |
| --- | --- | --- | --- |
| 原子 | 无业务含义的最小单位 | 无 | Button, Input |
| 复合 | 组合原子解决具体 UI 模式 | 原子 | Form, Modal |
| 业务 | 承载业务语义 | 原子 + 复合 + 领域 ViewModel | ForecastCard |
| 页面 | 路由入口，编排用例 | 业务 + 布局 | DashboardPage |
